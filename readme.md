# Technical Challenge Rick and Morty

## Network dependencies
Retrofit - Se lo utilizó, por ser estandar en desarrollo Android Nativo y su amplio soporte.

## Serialization
Kotlin Serializarion - Al ser una libreria propia de Kotlin es mas eficiente.

## Dependencies Injection
Hilt - Oficial de Google para Android y su soporte para Kotlin basados en Dagger, también podria usarse Koin

## Image Loading
Coil - Libreria hecha en Kotlin, y con mejor soporte para Compose, además de tener lo necesario para configurar cache

## Animation
Lottie - Libreria de animaciones ligera para añadir un placeholder de carga a las imagenes

## Arquitecture
MVVM - Clean Architecture, se uso una arquitectura basada en MVVM junto a algunas caracteristicas de Clean Architecture, como la capa de dominio

## UI
Jetpack Compose - Con soporte oficial de Google y el nuevo paradigma declarativo para construir UIs
